IA & MCP

Connecte ton compte commerce à Claude pour lui demander directement de créer des boutons de vérification, te donner le code à coller sur ton site, ou modifier ton profil commerce — le tout en langage naturel, sans repasser par ce site. Aucune installation nécessaire, juste un lien à copier-coller.

Exemples de demandes une fois connecté : « crée un bouton 18 ans pour l'entrée en salle », « liste mes boutons de vérification », « donne-moi le code du bouton Entrée soirée », « change mon âge minimum à 21 ans ».

Connecter Claude (recommandé — facile)

1. Copie ce lien

2. Ajoute-le dans Claude

Sur claude.ai (ou l'app Claude) → Paramètres → Connecteurs → Ajouter un connecteur personnalisé → colle le lien copié à l'étape 1 → valide.

3. C'est prêt

Demande-lui par exemple : « crée un bouton de vérification 18 ans et donne-moi le code à ajouter sur mon site ».

Ce lien donne accès uniquement à ton propre compte commerce (jamais aux comptes particuliers ni à l'admin) — garde-le secret comme un mot de passe. Régénérer le lien invalide immédiatement l'ancien.

Option avancée — serveur local (Claude Code / Claude Desktop)

Tu préfères Claude Code avec un serveur MCP local plutôt qu'un connecteur distant ? Le code source et les instructions sont dans mcp-server/README.md (fichiers index.js et package.json à télécharger). Cette option nécessite Node.js installé sur ta machine.

Sécurité

Le lien MCP n'a accès qu'à ton compte commerce : tes boutons de vérification et ton profil commerce. Il ne peut jamais lire ni modifier les comptes particuliers, ni accéder au panneau admin. Chaque action passée par Claude est exécutée par le même serveur que celui utilisé par cette page — rien de plus n'est possible.
